# CE-ESY-assignments
المخزن الدائري (Circular): بيستخدم معامل الباقي % عشان يرجع المؤشر للبداية (Index 0) لما يوصل لآخر مصفوفة، وهيك بيوفر استهلاك الذاكرة.
حالات الامتلاء والفراغ:
Overflow (الامتلاء): لما تحاول تكتب وبيكون الـ count بيساوي حجم المصفوفة.
Underflow (الفراغ): لما تحاول تقرأ وبيكون الـ count صفر.
مؤشرات القراءة والكتابة:
Head (الكتابة): المكان اللي رح تنحط فيه البيانات الجديدة.
Tail (القراءة): المكان اللي رح نسحب منه البيانات
